API (sigla para Application Programming Interface, ou Interface de Programação de Aplicações) é um conjunto de regras, padrões e protocolos que permite que diferentes sistemas ou programas conversem entre si e troquem dados. Ela funciona como uma ponte ou um intermediário: um sistema faz um pedido e outro devolve uma resposta, sem que o primeiro precise conhecer os detalhes internos de como o segundo funciona.
